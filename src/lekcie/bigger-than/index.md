## Porovnávame: -er than

Keď porovnávame dve veci, pridáme k vlastnosti <span class="f-ruzova">-er</span> a medzi veci dáme <span class="f-cervena">than</span> (= ako).

<ul class="farebne-vety">
<li><span class="f-modra">This cow</span> <span class="f-okrova">is</span> <span class="f-fialova">bigg</span><span class="f-ruzova">er</span> <span class="f-cervena">than</span> <span class="f-zelena">that cow.</span><small>Táto krava je väčšia ako tamtá krava.</small></li>
<li><span class="f-modra">This sheep</span> <span class="f-okrova">is</span> <span class="f-fialova">small</span><span class="f-ruzova">er</span> <span class="f-cervena">than</span> <span class="f-zelena">that sheep.</span><small>Táto ovca je menšia ako tamtá ovca.</small></li>
<li><span class="f-modra">The horse</span> <span class="f-okrova">is</span> <span class="f-fialova">tall</span><span class="f-ruzova">er</span> <span class="f-cervena">than</span> <span class="f-zelena">the goat.</span><small>Kôň je vyšší ako koza.</small></li>
</ul>
