## We've got = máme

<ul class="farebne-vety">
<li><span class="f-modra">We've got</span> = <span class="f-modra">We have got</span> = <span class="f-modra">máme</span><small>'ve je skrátené have.</small></li>
</ul>

## Otázka: ČO máme? → What

Keď sa pýtaš **čo** máme, začni slovom <span class="f-cervena">What</span>. Odpovieš **predmetom**.

<ul class="farebne-vety">
<li><span class="f-cervena">What</span> <span class="f-modra">have we got</span> <span class="f-okrova">on Monday?</span><small><span class="f-cervena">Čo</span> <span class="f-modra">máme</span> <span class="f-okrova">v pondelok?</span></small></li>
<li><span class="f-modra">We've got</span> <span class="f-zelena">English.</span><small><span class="f-modra">Máme</span> <span class="f-zelena">angličtinu.</span></small></li>
</ul>

## Otázka: KEDY máme? → When

Keď sa pýtaš **kedy** máme, začni slovom <span class="f-cervena">When</span>. Odpovieš **dňom**: <span class="f-okrova">on</span> + deň.

<ul class="farebne-vety">
<li><span class="f-cervena">When</span> <span class="f-modra">have we got</span> <span class="f-zelena">PE?</span><small><span class="f-cervena">Kedy</span> <span class="f-modra">máme</span> <span class="f-zelena">telesnú?</span></small></li>
<li><span class="f-modra">We've got</span> <span class="f-zelena">PE</span> <span class="f-okrova">on Thursday.</span><small><span class="f-zelena">Telesnú</span> <span class="f-modra">máme</span> <span class="f-okrova">vo štvrtok.</span></small></li>
</ul>

Pozor na poradie slov v otázke: najprv <span class="f-modra">have</span>, potom <span class="f-modra">we</span> – <span class="f-cervena">What</span> <span class="f-modra">have we got</span>…?

## our × their – komu to patrí?

<ul class="farebne-vety">
<li><span class="f-fialova">we</span> (my) → <span class="f-fialova">our</span> = náš, naša, naše<small>This is <span class="f-fialova">our</span> classroom. – Toto je <span class="f-fialova">naša</span> trieda.</small></li>
<li><span class="f-ruzova">they</span> (oni) → <span class="f-ruzova">their</span> = ich<small>That is <span class="f-ruzova">their</span> teacher. – Tamto je <span class="f-ruzova">ich</span> učiteľ.</small></li>
</ul>
