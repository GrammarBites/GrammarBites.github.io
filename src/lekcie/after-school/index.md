## ✓ Robím to

Na začiatku je <span class="f-modra">I</span> (ja), potom <span class="f-zelena">činnosť</span>. Ak to robíš pravidelne, pridaj <span class="f-okrova">every</span> + deň.

<ul class="farebne-vety">
<li><span class="f-modra">I</span> <span class="f-zelena">go swimming</span> <span class="f-okrova">every Monday.</span><small><span class="f-okrova">Každý pondelok</span> <span class="f-zelena">chodím plávať.</span></small></li>
<li><span class="f-modra">I</span> <span class="f-zelena">help my mum</span> <span class="f-okrova">every Tuesday.</span><small><span class="f-okrova">Každý utorok</span> <span class="f-zelena">pomáham mame.</span></small></li>
</ul>

<span class="f-okrova">every</span> = každý: <span class="f-okrova">every Monday</span> = každý pondelok, <span class="f-okrova">every day</span> = každý deň.

## ✗ Nerobím to

Medzi <span class="f-modra">I</span> a <span class="f-zelena">činnosť</span> vlož <span class="f-cervena">don't</span>. Po slovensky je to predpona <span class="f-cervena">ne-</span>.

<ul class="farebne-vety">
<li><span class="f-modra">I</span> <span class="f-cervena">don't</span> <span class="f-zelena">watch TV.</span><small><span class="f-cervena">Ne</span><span class="f-zelena">pozerám telku.</span></small></li>
<li><span class="f-modra">I</span> <span class="f-cervena">don't</span> <span class="f-zelena">have a music lesson.</span><small><span class="f-cervena">Ne</span><span class="f-zelena">mám hodinu hudby.</span></small></li>
</ul>

<span class="f-cervena">don't</span> = do not (skrátene).
