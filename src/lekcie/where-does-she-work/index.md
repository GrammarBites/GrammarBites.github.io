## Kde pracuje? → works in a …

Pri <span class="f-modra">he</span> a <span class="f-modra">she</span> pridáme k work **-s**. Miesto: <span class="f-fialova">in a …</span> = v …

<ul class="farebne-vety">
<li><span class="f-modra">He</span> <span class="f-zelena">work</span><span class="f-ruzova">s</span> <span class="f-fialova">in a hospital.</span><small><span class="f-zelena">Pracuje</span> <span class="f-fialova">v nemocnici.</span></small></li>
<li><span class="f-modra">She</span> <span class="f-zelena">work</span><span class="f-ruzova">s</span> <span class="f-fialova">in a shop.</span><small><span class="f-zelena">Pracuje</span> <span class="f-fialova">v obchode.</span></small></li>
</ul>

Pred slovom, ktoré začína samohláskou, je **an**: <span class="f-fialova">in an airport</span>.

## Otázka: Where does he work?

<span class="f-cervena">Where</span> = Kde? V otázke je <span class="f-okrova">does</span> a <span class="f-zelena">work</span> je **bez -s** (to -s už je v *does*).

<ul class="farebne-vety">
<li><span class="f-cervena">Where</span> <span class="f-okrova">does</span> <span class="f-modra">he</span> <span class="f-zelena">work?</span><small><span class="f-cervena">Kde</span> <span class="f-zelena">pracuje?</span></small></li>
<li><span class="f-modra">He</span> <span class="f-zelena">work</span><span class="f-ruzova">s</span> <span class="f-fialova">in a school.</span><small><span class="f-zelena">Pracuje</span> <span class="f-fialova">v škole.</span></small></li>
</ul>

## Otázka: Does she work …?

Keď sa pýtame áno/nie, <span class="f-okrova">Does</span> ide na začiatok.

<ul class="farebne-vety">
<li><span class="f-okrova">Does</span> <span class="f-modra">she</span> <span class="f-zelena">work</span> <span class="f-fialova">in an airport?</span><small><span class="f-zelena">Pracuje</span> <span class="f-fialova">na letisku?</span></small></li>
<li><span class="f-zelena">Yes,</span> <span class="f-modra">she</span> <span class="f-okrova">does.</span><small>Áno.</small></li>
<li><span class="f-cervena">No,</span> <span class="f-modra">she</span> <span class="f-cervena">doesn't.</span><small>Nie. (<span class="f-cervena">doesn't</span> = does not)</small></li>
</ul>
