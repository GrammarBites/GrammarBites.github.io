## I, you, we, they → like

<span class="f-fialova">like</span> = mám rád. <span class="f-cervena">don't</span> <span class="f-fialova">like</span> = nemám rád.

<ul class="farebne-vety">
<li><span class="f-modra">I</span> <span class="f-fialova">like</span> <span class="f-zelena">balloons.</span><small><span class="f-fialova">Mám rád</span> <span class="f-zelena">balóny.</span></small></li>
<li><span class="f-modra">I</span> <span class="f-cervena">don't</span> <span class="f-fialova">like</span> <span class="f-zelena">sweets.</span><small><span class="f-cervena">Nemám rád</span> <span class="f-zelena">cukríky.</span></small></li>

## he, she → likes

Pri <span class="f-modra">he</span> a <span class="f-modra">she</span> pridáme k like **-s**: <span class="f-fialova">like</span><span class="f-ruzova">s</span>. V zápore je <span class="f-cervena">doesn't</span> a like je **znova bez -s**.

<ul class="farebne-vety">
<li><span class="f-modra">He</span> <span class="f-fialova">like</span><span class="f-ruzova">s</span> <span class="f-zelena">chocolate.</span><small><span class="f-fialova">Má rád</span> <span class="f-zelena">čokoládu.</span></small></li>
<li><span class="f-modra">She</span> <span class="f-cervena">doesn't</span> <span class="f-fialova">like</span> <span class="f-zelena">cake.</span><small><span class="f-cervena">Nemá rada</span> <span class="f-zelena">tortu.</span></small></li>
</ul>

## Otázka: What … like?

Pri <span class="f-modra">I, you</span> je <span class="f-okrova">do</span>, pri <span class="f-modra">he, she</span> je <span class="f-okrova">does</span>.

<ul class="farebne-vety">
<li>What <span class="f-okrova">do</span> <span class="f-modra">you</span> <span class="f-fialova">like?</span> – <span class="f-modra">I</span> <span class="f-fialova">like</span> <span class="f-zelena">cake.</span><small>Čo máš rád? – Mám rád tortu.</small></li>

</ul>
