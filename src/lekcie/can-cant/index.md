## Viem × neviem

<span class="f-fialova">can</span> = viem, môžem. <span class="f-cervena">can't</span> = neviem. Po <span class="f-fialova">can</span> ide činnosť **bez to a bez -s** – aj pri he a she.

<ul class="farebne-vety">
<li><span class="f-modra">I</span> <span class="f-fialova">can</span> <span class="f-zelena">skate.</span><small><span class="f-fialova">Viem</span> <span class="f-zelena">korčuľovať sa.</span></small></li>
<li><span class="f-modra">I</span> <span class="f-cervena">can't</span> <span class="f-zelena">ride a horse.</span><small><span class="f-cervena">Neviem</span> <span class="f-zelena">jazdiť na koni.</span></small></li>
<li><span class="f-modra">She</span> <span class="f-fialova">can</span> <span class="f-zelena">play tennis.</span><small><span class="f-fialova">Vie</span> <span class="f-zelena">hrať tenis.</span></small></li>
</ul>

## Otázka: Can she …?

V otázke ide <span class="f-fialova">can</span> **na začiatok**: <span class="f-modra">She</span> <span class="f-fialova">can</span> play tennis. → <span class="f-fialova">Can</span> <span class="f-modra">she</span> play tennis?

<ul class="farebne-vety">
<li><span class="f-fialova">Can</span> <span class="f-modra">she</span> <span class="f-zelena">play tennis?</span><small><span class="f-fialova">Vie</span> <span class="f-zelena">hrať tenis?</span></small></li>
<li><span class="f-zelena">Yes,</span> <span class="f-modra">she</span> <span class="f-fialova">can.</span><small>Áno, vie.</small></li>
<li><span class="f-cervena">No,</span> <span class="f-modra">he</span> <span class="f-cervena">can't.</span><small>Nie, nevie.</small></li>
</ul>

K tomuto unitu patria aj **predložky miesta** (behind, in front of, next to, between) – nájdeš ich v lekcii [Predložky miesta](/lekcie/prepositions-of-place/).
