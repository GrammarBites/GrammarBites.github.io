## Máš …? → Have you got …?

Pri <span class="f-modra">I</span> a <span class="f-modra">you</span> je <span class="f-fialova">have</span>. Krátka odpoveď je **bez got**.

<ul class="farebne-vety">
<li><span class="f-fialova">Have</span> <span class="f-modra">you</span> <span class="f-fialova">got</span> <span class="f-zelena">a milkshake?</span><small><span class="f-fialova">Máš</span> <span class="f-zelena">mliečny kokteil?</span></small></li>
<li><span class="f-zelena">Yes,</span> <span class="f-modra">I</span> <span class="f-fialova">have.</span><small>Áno, mám.</small></li>
<li><span class="f-cervena">No,</span> <span class="f-modra">I</span> <span class="f-cervena">haven't.</span><small>Nie, nemám. (<span class="f-cervena">haven't</span> = have not)</small></li>
</ul>

## Má …? → Has he got …?

Pri <span class="f-modra">he</span> a <span class="f-modra">she</span> je <span class="f-ruzova">has</span>.

<ul class="farebne-vety">
<li><span class="f-ruzova">Has</span> <span class="f-modra">he</span> <span class="f-ruzova">got</span> <span class="f-zelena">a cheese sandwich?</span><small><span class="f-ruzova">Má</span> <span class="f-zelena">syrový sendvič?</span></small></li>
<li><span class="f-zelena">Yes,</span> <span class="f-modra">he</span> <span class="f-ruzova">has.</span><small>Áno, má.</small></li>
<li><span class="f-cervena">No,</span> <span class="f-modra">she</span> <span class="f-cervena">hasn't.</span><small>Nie, nemá. (<span class="f-cervena">hasn't</span> = has not)</small></li>
</ul>
