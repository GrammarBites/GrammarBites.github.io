## My sme · Oni sú

<span class="f-modra">We're</span> = <span class="f-modra">We</span> <span class="f-okrova">are</span> = my sme. <span class="f-fialova">They're</span> = <span class="f-fialova">They</span> <span class="f-okrova">are</span> = oni sú.

<ul class="farebne-vety">
<li><span class="f-modra">We're</span> <span class="f-zelena">happy.</span><small><span class="f-modra">(My)</span> <span class="f-okrova">sme</span> <span class="f-zelena">šťastní.</span></small></li>
<li><span class="f-fialova">They're</span> <span class="f-zelena">hungry.</span><small><span class="f-fialova">(Oni)</span> <span class="f-okrova">sú</span> <span class="f-zelena">hladní.</span></small></li>
</ul>

## Otázka: Are they …?

V otázke ide <span class="f-okrova">are</span> **na začiatok**: <span class="f-fialova">They</span> <span class="f-okrova">are</span> happy. → <span class="f-okrova">Are</span> <span class="f-fialova">they</span> happy?

<ul class="farebne-vety">
<li><span class="f-okrova">Are</span> <span class="f-fialova">they</span> <span class="f-zelena">happy?</span><small><span class="f-okrova">Sú</span> <span class="f-zelena">šťastní?</span></small></li>
<li><span class="f-zelena">Yes,</span> <span class="f-fialova">they</span> <span class="f-okrova">are.</span><small>Áno, sú.</small></li>
<li><span class="f-cervena">No,</span> <span class="f-fialova">they</span> <span class="f-cervena">aren't.</span><small>Nie, <span class="f-cervena">nie sú</span>. (<span class="f-cervena">aren't</span> = are not)</small></li>
</ul>
