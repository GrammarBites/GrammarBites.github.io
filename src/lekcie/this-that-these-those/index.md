## Jedna vec → is

Ak je vec **blízko** (môžem sa jej dotknúť), poviem <span class="f-modra">this</span>. Ak je **ďaleko** (ukazujem na ňu prstom), poviem <span class="f-cervena">that</span>.

<ul class="farebne-vety">
<li><span class="f-modra">This</span> <span class="f-okrova">is</span> <span class="f-zelena">a computer.</span><small><span class="f-modra">Toto</span> <span class="f-okrova">je</span> <span class="f-zelena">počítač.</span></small></li>
<li><span class="f-cervena">That</span> <span class="f-okrova">is</span> <span class="f-zelena">a board.</span><small><span class="f-cervena">Tamto</span> <span class="f-okrova">je</span> <span class="f-zelena">tabuľa.</span></small></li>
</ul>

## Viac vecí → are

Pri viacerých veciach poviem <span class="f-modra">these</span> (blízko) alebo <span class="f-cervena">those</span> (ďaleko) a vždy <span class="f-okrova">are</span>. Vec dostane na konci **-s**: table → table<span class="f-zelena">s</span>.

<ul class="farebne-vety">
<li><span class="f-modra">These</span> <span class="f-okrova">are</span> <span class="f-zelena">tables.</span><small><span class="f-modra">Toto</span> <span class="f-okrova">sú</span> <span class="f-zelena">stoly.</span></small></li>
<li><span class="f-cervena">Those</span> <span class="f-okrova">are</span> <span class="f-zelena">pegs.</span><small><span class="f-cervena">Tamto</span> <span class="f-okrova">sú</span> <span class="f-zelena">vešiaky.</span></small></li>
</ul>
