## Aké je počasie?

<ul class="farebne-vety">
<li><span class="f-cervena">What's the weather like?</span><small>Aké je počasie?</small></li>
<li><span class="f-modra">It's</span> <span class="f-okrova">sunny.</span><small>Je <span class="f-okrova">slnečno.</span></small></li>
<li><span class="f-modra">It's</span> <span class="f-okrova">raining.</span><small><span class="f-okrova">Prší.</span></small></li>
</ul>

Pri počasí začíname vždy <span class="f-modra">It's</span> (= It is). Po slovensky ho často nepovieme (*Prší.*), ale v angličtine **nesmie chýbať**.

## ✓ Urob to! – príkaz

Príkaz začína **hneď činnosťou** – bez *I* alebo *you*.

<ul class="farebne-vety">
<li><span class="f-fialova">Put on</span> <span class="f-zelena">your sun hat.</span><small><span class="f-fialova">Daj si</span> <span class="f-zelena">klobúk proti slnku.</span></small></li>
<li><span class="f-fialova">Open</span> <span class="f-zelena">the window.</span><small><span class="f-fialova">Otvor</span> <span class="f-zelena">okno.</span></small></li>
</ul>

## ✗ Nerob to! – Don't …

Zákaz začína <span class="f-cervena">Don't</span> + činnosť. Po slovensky je to predpona <span class="f-cervena">ne-</span>.

<ul class="farebne-vety">
<li><span class="f-cervena">Don't</span> <span class="f-fialova">put on</span> <span class="f-zelena">your coat.</span><small><span class="f-cervena">Ne</span><span class="f-fialova">obliekaj si</span> <span class="f-zelena">kabát.</span></small></li>
<li><span class="f-cervena">Don't</span> <span class="f-fialova">open</span> <span class="f-zelena">the door.</span><small><span class="f-cervena">Ne</span><span class="f-fialova">otváraj</span> <span class="f-zelena">dvere.</span></small></li>
</ul>
