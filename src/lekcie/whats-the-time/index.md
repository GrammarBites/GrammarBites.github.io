## Koľko je hodín?

<ul class="farebne-vety">
<li><span class="f-cervena">What's the time?</span><small>Koľko je hodín?</small></li>
<li>It's <span class="f-okrova">seven o'clock.</span><small>Je <span class="f-okrova">sedem hodín.</span></small></li>
</ul>

<span class="f-okrova">o'clock</span> = presne celá hodina. Na hodinách je veľká ručička na **12** a malá ukazuje hodinu.

## Kedy? → at

Keď hovoríš, **o koľkej** niečo robíš, použi <span class="f-okrova">at</span> + čas.

<ul class="farebne-vety">
<li><span class="f-modra">I</span> <span class="f-zelena">get up</span> <span class="f-okrova">at seven o'clock.</span><small><span class="f-zelena">Vstávam</span> <span class="f-okrova">o siedmej.</span></small></li>
<li><span class="f-modra">I</span> <span class="f-zelena">go to bed</span> <span class="f-okrova">at nine o'clock.</span><small><span class="f-zelena">Idem spať</span> <span class="f-okrova">o deviatej.</span></small></li>
</ul>

## On, ona → -s

Pri <span class="f-modra">he</span> a <span class="f-modra">she</span> pridáme k činnosti **-s** (pri *go* **-es**). Pozor: *have* sa mení na <span class="f-ruzova">has</span>.

<ul class="farebne-vety">
<li><span class="f-modra">He</span> <span class="f-zelena">get</span><span class="f-ruzova">s</span> <span class="f-zelena">up</span> <span class="f-okrova">at six o'clock.</span><small><span class="f-zelena">Vstáva</span> <span class="f-okrova">o šiestej.</span></small></li>
<li><span class="f-modra">She</span> <span class="f-zelena">go</span><span class="f-ruzova">es</span> <span class="f-zelena">to bed</span> <span class="f-okrova">at nine o'clock.</span><small><span class="f-zelena">Ide spať</span> <span class="f-okrova">o deviatej.</span></small></li>
<li><span class="f-modra">He</span> <span class="f-ruzova">has</span> <span class="f-zelena">dinner</span> <span class="f-okrova">at seven o'clock.</span><small><span class="f-zelena">Večeria</span> <span class="f-okrova">o siedmej.</span></small></li>
</ul>
