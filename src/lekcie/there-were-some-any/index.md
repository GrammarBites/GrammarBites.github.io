## Ľudia

<table class="chyby tvary">
<thead><tr><th scope="col">po anglicky</th><th scope="col">po slovensky</th></tr></thead>
<tbody>
<tr><td><span class="f-fialova">man → men</span></td><td>muž → muži</td></tr>
<tr><td><span class="f-fialova">woman → women</span></td><td>žena → ženy</td></tr>
<tr><td><span class="f-fialova">child → children</span></td><td>dieťa → deti</td></tr>

</tbody>
</table>

Pozor: <span class="f-fialova">men, women, children</span> sú množné číslo **bez -s**. Nikdy nie ~~mans~~, ~~womans~~, ~~childs~~.

## ✗ Neboli tam … → There weren't any

<ul class="farebne-vety">
<li><span class="f-modra">There</span> <span class="f-cervena">weren't</span> <span class="f-okrova">any</span> <span class="f-fialova">children.</span><small>Neboli tam žiadne deti.</small></li>

</ul>

Pravidlo: pri <span class="f-ruzova">were</span> je <span class="f-okrova">some</span>, pri <span class="f-cervena">weren't</span> je <span class="f-okrova">any</span>.
